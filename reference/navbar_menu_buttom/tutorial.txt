Langsung ini urutan dari nol supaya bisa dipindah ke project lain dan langsung menyatu dengan sistem yang sudah ada.

1. File Yang Wajib Di-Copy
Copy persis 3 file ini dari project sekarang:

bottom_navbar.php
bottom-navbar.blade.php
navbar-menu-item.blade.php
2. Susunan Folder Di Project Tujuan
Pastikan folder di project tujuan mengikuti struktur ini:

config/
resources/views/components/
Hasil akhirnya harus seperti ini:

bottom_navbar.php
bottom-navbar.blade.php
navbar-menu-item.blade.php
3. Langkah Integrasi Ke Layout Existing

Buka layout utama frontend di project tujuan (misalnya layout app).
Tambahkan include komponen navbar di bagian bawah body/content:
@include('components.bottom-navbar')
Gunakan pola dari app.blade.php sebagai referensi posisi include.
4. Dependency Yang Harus Sudah Ada
Agar fitur sama persis (dropdown, hover, active state), pastikan:

AlpineJS aktif di frontend project tujuan.
Tailwind utility class aktif (karena komponen pakai kelas utility).
Material Symbols font dimuat di head layout.
Jika pakai Vite, entry JS/CSS sudah ter-load di layout.
Referensi setup yang sekarang dipakai:

app.js
app.css
5. Pengisian Menu (Supaya Langsung Nyambung Route Existing)
Semua menu diatur dari satu tempat: bottom_navbar.php

Per item:

route: nama route Laravel
label: teks menu
icon: nama material symbol
active_routes: array route yang dianggap aktif
dropdown: submenu jika diperlukan
url: opsional, jika ingin link langsung tanpa named route
Catatan: kalau route belum ada, komponen tidak crash (sudah ada fallback).

6. Urutan Eksekusi Setelah Copy

Simpan semua file.
Jalankan clear config cache:
php artisan config:clear
Jalankan build asset frontend sesuai project (dev/build).
Cek halaman frontend dan klik semua menu + dropdown.
